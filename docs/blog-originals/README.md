# Replaced blog posts

The only copy of a published blog post is its `blog_posts` row — there is no
revision history on that table. So when a rewrite replaces a post that was
already live, the version it replaced is archived here, where git keeps it.

A new post needs nothing in this folder; only a REWRITE of something already
published does.

- `questions-to-ask-before-accepting-ski-season-job.md` — replaced 2026-10-10
  by the Weeks 3-4 AEO guide of the same slug (see AEO.md). The original was
  1,893 characters with no FAQ section and no live figures.
